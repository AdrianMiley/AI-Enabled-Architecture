#   Myths

There is no such thing as...

-   A Single Source Of The Truth 
-   A finished Data Model – at best a model that is “fit for purpose” and there is always stuff that we might add later if the need arises.
-   An “optional” Data-Item – every Data Item must be mandatory in at least one Business Activity otherwise why are we interested in it?
-   An “exception to the rule” – all rules have a (either implicit or explicit) defined scope and exceptions are simply unplanned scenarios that fall outside that scope.
-   An unconstrained Data-Item – all Data-Items are restricted in some way but the restrictions may not be significant.
-   A “one size fits all” Data Model – each Activity has a specific view of the Data and that view should only encompass Data-Items required to complete the Activity.
-   A fully normalised Data Model – every value is a copy of a value originating from somewhere else
